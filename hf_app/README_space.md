# FinShield - AI-Powered Fraud Detection Platform

End-to-end fraud detection system combining XGBoost, BiLSTM, and LLM+RAG.

Built as a portfolio project targeting ML Engineer and Data Scientist roles at Indian fintech companies (Razorpay, PhonePe, HDFC Bank, Navi).

**Tech stack:** XGBoost · PyTorch BiLSTM · LangChain RAG · MLflow · Evidently AI · FastAPI · Streamlit · Docker
