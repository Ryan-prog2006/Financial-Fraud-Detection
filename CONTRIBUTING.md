# Contributing to FinShield

To contribute to FinShield, please follow these guidelines:
1. Run the local unit test suite using the command 'pytest tests/ -v' to ensure all changes are functional.
2. Ensure your changes do not introduce any deprecation warnings or performance regressions.
3. Open a detailed issue on GitHub describing any bugs or proposed features before submitting a pull request.
4. Format all Python source code using black and check typing rules before committing.
5. Create a clean branch from develop and submit your pull request targeting the develop branch.
